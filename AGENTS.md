# Micro-drama workspace trigger

When the user says **Start Micro Drama** (case-insensitive, punctuation-insensitive), begin the user's micro-drama workflow immediately. Do not ask what the trigger means.

Before starting, read the latest `SYSTEM_PROMPT.md` and `VIDEO_EDITING_SYSTEM_PROMPT.md` at this repository root. Fast-forward this clone from `origin/main` when possible; if the clone is unavailable, read the canonical files at https://github.com/akinluyigithub/micro-drama-system-prompt.

Immediately after loading the prompts, execute the browser action (do not merely state an intention): call `cua.getTab({ url: "https://app.videoexpress.ai/" }, { browser: "iab" })` via `mcp__cua_repl.js`; if no tab is found, call `cua.createBrowserTab("iab", "https://app.videoexpress.ai/", { visible: true })`. If using research agents, dispatch them and open the browser while they work. Verify returned URL, loaded app UI, and signed-in account indicator. Keep the VideoExpress tab open across turns and after project completion; never close it as cleanup or navigate away at handoff. Reuse it next time, and reopen if missing. It cannot survive the user closing the app/browser session. If CUA is unavailable, use Codex `open_in_codex` with this exact browser URL. Stop and report any login/access gate. Do not generate before the usual approvals.

Before recommending or refining a concept, do a 60–90 second scan of at least three accessible sources, prioritizing TikTok, YouTube Shorts, and Instagram Reels; stop by two minutes, cite findings, and disclose access gaps. If no user story was supplied, then lead with one structured recommendation (title, Protagonist, Goal, Opposition, Secret, Stakes, Visual Hook, Why this works), then show lettered genre alternatives and a numbered choice board ending with **I have my own story**. If the user included a story with the trigger, use it directly. Follow the system prompt's consolidated brief, including the still-image generation route question. Create a separate project-title folder in the current workspace after the title is established. Use VideoExpress for all video animation and production. If the user picks a different type, generate a full premise in that type and ask for a simple next choice; if they say “something else,” offer A another premise in the same style, B a different style, C their own story. Continue the interactive loop until a premise is selected/approved or the user explicitly stops; never end or stop just because they rejected an option. Follow the approved-episode completion authorization in the system prompt.
