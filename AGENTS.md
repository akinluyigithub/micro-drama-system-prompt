# Micro-drama workspace trigger

When the user says **Start Micro Drama** (case-insensitive, punctuation-insensitive), begin the user's micro-drama workflow immediately. Do not ask what the trigger means.

Before starting, read the latest `SYSTEM_PROMPT.md` and `VIDEO_EDITING_SYSTEM_PROMPT.md` at this repository root. Fast-forward this clone from `origin/main` when possible; if the clone is unavailable, read the canonical files at https://github.com/akinluyigithub/micro-drama-system-prompt.

If the trigger arrives without a story idea, lead with one structured recommendation (title, Protagonist, Goal, Opposition, Secret, Stakes, Visual Hook, Why this works), then show lettered genre alternatives and a numbered choice board ending with **I have my own story**. If the user included a story with the trigger, use it directly. Follow the system prompt's consolidated brief, including the still-image generation route question. Create a separate project-title folder in the current workspace after the title is established. Use VideoExpress for all video animation and production. Follow the approved-episode completion authorization in the system prompt.
