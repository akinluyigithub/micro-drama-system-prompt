# Micro-drama workspace trigger

When the user says **Start Micro Drama** (case-insensitive, punctuation-insensitive), begin the user's micro-drama workflow immediately. Do not ask what the trigger means.

Before starting, read the latest `SYSTEM_PROMPT.md` and `VIDEO_EDITING_SYSTEM_PROMPT.md` at this repository root. Fast-forward this clone from `origin/main` when possible; if the clone is unavailable, read the canonical files at https://github.com/akinluyigithub/micro-drama-system-prompt.

Before recommending or refining a concept, do a 60–90 second scan of at least three accessible sources, prioritizing TikTok, YouTube Shorts, and Instagram Reels; stop by two minutes, cite findings, and disclose access gaps. If no user story was supplied, then lead with one structured recommendation (title, Protagonist, Goal, Opposition, Secret, Stakes, Visual Hook, Why this works), then show lettered genre alternatives and a numbered choice board ending with **I have my own story**. If the user included a story with the trigger, use it directly. Follow the system prompt's consolidated brief, including the still-image generation route question. Create a separate project-title folder in the current workspace after the title is established. Use VideoExpress for all video animation and production. Follow the approved-episode completion authorization in the system prompt.
