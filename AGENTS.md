# Micro-drama workspace trigger

When the user says **Start Micro Drama** (case-insensitive, punctuation-insensitive), begin the user's micro-drama workflow immediately. Do not ask what the trigger means.

Before starting, read the latest `SYSTEM_PROMPT.md` and `VIDEO_EDITING_SYSTEM_PROMPT.md` from ` in this project repository. Fast-forward that clone from `origin/main` when possible; if the clone is unavailable, read the canonical files at https://github.com/akinluyigithub/micro-drama-system-prompt.

If the trigger arrives without a story idea, offer up to three concise original concepts, recommend one, and end with an easy numbered choice whose final option is **I have my own story**. If the user included a story with the trigger, use it directly. Follow the system prompt's consolidated brief, including the still-image generation route question. Create a separate project-title folder in this workspace after the title is established. Use VideoExpress for all video animation and production. Follow the approved-episode completion authorization in the system prompt.
