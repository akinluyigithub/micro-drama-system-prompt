# Reusable Background Music Library

Original WAV tracks are mirrored here from the local `Audio-Background-Music` folder so they can be retrieved for future VideoExpress projects. The same files have also been imported into the current VideoExpress project's My Media > Audio library.

## How to use this library

- These tracks are a reusable library across projects; they are not all intended for any one episode.
- For a new project, first check its VideoExpress media library. If a track is not available there, retrieve the WAV from this folder or re-upload it into VideoExpress.
- Preview candidate tracks in VideoExpress and use only the track(s) that fit the scene, dialogue, pacing, and emotional arc. Keep dialogue clear and lower music under speech when the app supports it.
- The suggested cues below are tentative interpretations of the filenames only. They are not confirmed descriptions of the audio. Audition each track before assigning it.
- Preserve the source WAVs. Keep both `Calculated Risk.wav` and `Calculated Risk (1).wav`; their names are similar but they are separate files.

## Storage

This repository is public. WAV files are stored with Git LFS so ordinary Git history remains lightweight. The original local copies remain in `Audio-Background-Music`.
